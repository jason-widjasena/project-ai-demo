# 3.4 How Neural Networks Learn
Training is the process of updating weights and biases so the model's guesses get closer to the real values. In simple terms, this means the model improving itself so it gets “smarter” or better suited for its purpose.

## Training Step-by-Step

### Forward Propagation
Forward propagation is the first step, where input data travels from the input layer through the hidden layers until it reaches the output layer. As the data passes through each neuron, the network performs calculations using its weights and biases to produce a prediction.

For example, imagine we want a neural network to predict the price of a house. We provide information such as the house's size, location, and number of bedrooms. The network processes this information and predicts that the house costs $300,000. At this stage, the network is simply making its best guess based on what it has learned so far. It has not checked whether the prediction is correct yet.

### Loss Function Calculation
After making a prediction, the network needs to measure how accurate it is. This is done using a loss function, which calculates the difference between the predicted value and the actual value.

For example:
* Predicted house price: $300,000
* Actual house price: $250,000
* Prediction error: $50,000

The loss function uses this difference to calculate how wrong the prediction is. A higher loss means the prediction is further from the correct answer, while a lower loss means the prediction is more accurate. The main goal of training is to reduce this loss as much as possible so that the network can make better predictions in the future.

### Backpropagation
Once the network knows how much error it has made, it needs to figure out how to improve. This is where backpropagation comes in. Backpropagation is the process of sending information about the error backward through the network, starting from the output layer and moving toward the earlier layers. It calculates how much each weight contributed to the final error. In simple terms, it helps the network understand which internal values need to change to make a better prediction.

For example, if the network predicts a house price that is too high, backpropagation calculates how the weights connected to house size, location, and other inputs affected that prediction. It then provides information that helps the network adjust those weights.

### Gradient Descent and Learning Rate
After backpropagation calculates the information needed to improve the network, gradient descent uses it to update the weights and biases. Gradient descent is an optimization method that helps the network find values that produce a lower loss. It does this by gradually adjusting the weights in the direction that reduces the error. The size of each adjustment is controlled by something called the learning rate. The learning rate determines how big or small each update should be.

There are two common problems with choosing the learning rate:
* Too Large Learning Rate: The network makes very large adjustments to its weights. It may jump over the best values and struggle to find the lowest error, making training unstable.
* Too Small Learning Rate: The network makes very small adjustments. Although it may eventually improve, training becomes very slow and requires many updates to reach a good result.
