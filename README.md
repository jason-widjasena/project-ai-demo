# The Code Theorists

**Topic:** Algorithms, Data Structures, & Connectionist AI  
**Target Audience:** Beginners with little to no experience in computer science. While they may know how to use AI for daily tasks, they don't understand the logic of how it works.  
**Overview:** A comprehensive and engaging set of learning materials for "Algorithms, Data Structures, & Connectionist AI."
